Reverses the byte order of an integral value (byte swap / endianness reverse), C++11 form.

Analogue of C++23 std::byteswap. The value is converted to the unsigned type of the same size, the bytes are reversed with shifts and masks, and the result is converted back, so signed values keep the bit pattern of the swapped bytes. It is constexpr and noexcept. From C++20 the same function name is the std::bit_cast and builtin based template; both give the same value.

Counts the leading zero bits of an unsigned integer (C++11).

Analogue of C++20 std::countl_zero for an unsigned integer of 1, 2, 4 or 8 bytes. bool and wider types, including unsigned __int128, are not in the overload set: the intrinsics below scan 32 or 64 bits, and a wider value would be truncated. A zero value returns the bit width. The function is not constexpr: the MSVC intrinsics are not constant expressions on the toolchains this library supports.

Template Parameters
NumericTypeUnsigned integer, not bool, of 1, 2, 4 or 8 bytes.
Parameters
[in]valueInput value.
Returns
The number of consecutive zero bits from the most significant bit, in the range 0 .. sizeof(NumericType) * 8.
Note
Exception-safety: nothrow (the function is noexcept).
Thread-safety: yes, no shared state is used.

◆ is_little_endian()

bool lumex::core::utility::bit::is_little_endian ( )
inlinenoexcept

Tells whether the machine stores the least significant byte of an integer first (little endian).

Reads the first byte of the object representation of the 32-bit value 1 through std::memcpy, so it has no undefined behavior. A middle endian machine counts as not little endian.

Returns
true on a little endian machine (x86, x86-64 and, in practice, ARM and every Windows target), false otherwise.
