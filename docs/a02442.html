Detailed Description

Base exception that records the stack where it was constructed.

lumex_base_exception(char const *), both std::string constructors, to_stderr and to_crash_report are exported and have the same signature in every C++ standard, so a consumer built at another standard than the library links. The string view constructor (lumex_string_view of lumex::string_view, in every standard) is an inline wrapper over std::string &&. The class itself is not exported: a dllimport class makes clang-cl emit an import for an inline member it does not inline, and the library does not provide the standard-dependent constructor.
