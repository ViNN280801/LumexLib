Detailed Description

Resource monitor module: a background thread that samples the CPU and RAM usage of the system (and of watched processes) and appends one line per sample to a dated log file, and the CPU and RAM of single processes on request.

Link lumex::resource_monitor (compiled library). The library compiles from C++11 and uses the library's own optional, lumex_string_view and filesystem. The umbrella includes monitor/LumexResourceMonitor.hpp and process/LumexProcessMonitor.hpp.
