inlinenoexcept

The handler of a violated precondition: prints LUMEX_SPAN_CHECKS: <condition> failed at <file>:<line> to standard error and aborts. It returns int (never reached) so that the check can be static_cast<void> (condition ? 0 : check_failed (...)), a cast that is not a no-op on every compiler (-Wuseless-cast). Not constexpr, so a violated check in a constant expression is a compile error. On the MSVC debug runtime std::abort may show a modal dialog.

Parameters
conditionThe text of the failed condition.
fileThe source file of the check.
lineThe line of the check.
