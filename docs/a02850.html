Detailed Description

A bidirectional iterator for traversing attributes of an XmlNode.

This iterator allows standard C++ algorithm usage and range-based for loops over a node's attributes. It wraps an XmlAttribute object (m_wrap) and keeps a reference to its parent XmlNode for reverse iteration and boundary checks (e.g., finding the last attribute of the parent from a singular iterator).

Note
The iterator holds a mutable XmlAttribute to allow its internal pointer to be updated during traversal.
See also
XmlNode::attributes_begin()
XmlNode::attributes_end()
