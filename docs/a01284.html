◆ descendants_of()

std::vector< process_id_t > lumex::applied::resource_monitor::process::detail::descendants_of ( process_id_t root,
std::vector< process_link_t > const & links )

Every process below one process: its children, their children, and so on.

Parameters
rootThe process ID to start from. It does not have to be in links.
linksThe processes that exist, with their parents.
Returns
The IDs below root, nearest first, each once. A process is left out (with everything below it) when it started before its parent: the parent's ID was then reused by another process, and the link is stale. A process that is its own parent (Windows' idle process) has no children of its own.
