Internal implementation for loading an XML document from a buffer.

Parameters
[in,out]docThe XmlDocumentBase object to populate with parsed data.
[in,out]rootThe root XmlNodeBase where the parsed document structure will be attached.
[in]contentsA pointer to the raw input data buffer.
[in]sizeThe size of the input buffer in bytes.
[in]optionsA bitmask of xml_parse_option flags controlling parsing behavior.
[in]encodingThe expected character encoding of the buffer.
[in]is_mutabletrue if the input buffer can be modified by the parser, false otherwise.
[in]owntrue if the parser should take ownership of contents and deallocate it, false otherwise.
[out]out_bufferA pointer to a char_t* that will receive the pointer to the internal buffer used for parsing.
Returns
An xml_parse_result_t object indicating the parsing outcome.

This function handles buffer conversion, BOM skipping, memory ownership, and dispatches to the main XML parsing logic. It is an internal utility function called by XmlDocument::load.
