Detailed Description

Internal deadline engine of the serial prober.

Header-only detail::run_probe: it opens the port when needed, purges the buffers, writes the request and reads until the caller's predicate confirms the response, the response cap is reached or the deadline expires. The public contract lives in LumexSerialProber.hpp. Consumers must not include this header.
