Detailed Description

Counting policy: the size in bytes of the UTF-8 form of what a decoder yields.

A decoder (utf8_decoder, utf16_decoder, ...) calls low for every code point below U+10000 and high for every code point from U+10000 on, and threads result through the calls. This policy adds 1, 2 or 3 bytes for low and 4 for high. Run it first to size the buffer, then run utf8_writer over the same input.
