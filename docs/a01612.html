constexpr std::size_t k_max_sequence_size = 16384
 The most integers one own sequence holds. A longer one is refused (see make_integer_sequence); the standard library has no limit of its own, only the resources of the compiler. The value stays well below 32768: Clang 23 builds a list of 32768 or 65536 integers as an empty one without a diagnostic (32767 is still right).
