◆ check_std_enable_shared_from_this()

template<class Y>
void lumex::core::smart_ptr::detail::check_std_enable_shared_from_this ( )
noexcept

Rejects, with a static_assert, a class that derives from std::enable_shared_from_this and not from the module's own base.

Called by every operation that creates the owner of a new object (shared_ptr (Y *) and its variants, make_shared, allocate_shared): the standard base could not be set, so shared_from_this () of it would throw later. Turned off by LUMEX_SMART_PTR_ALLOW_STD_ENABLE_SHARED_FROM_THIS.
