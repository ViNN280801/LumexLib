Detailed Description

Header-only, C++11-first basic_string_view: the class template behind lumex_string_view, lumex_wstring_view and the other character views.

lumex_basic_string_view<CharT, Traits> is a non-owning view over a contiguous character sequence with the API of std::basic_string_view (C++17) plus what later standards added (contains, the range constructor, operator<=>), available from C++11. Everything is inline: there is no compiled part, no export macro and no library to link.

Constant evaluation follows the language of each standard. From C++14 every query is constexpr, and so are the modifiers (remove_prefix, remove_suffix, swap, clear, copy). In C++11 the queries are constexpr as well (a single return statement, loops replaced by a recursion that splits the range in halves, so its depth is the logarithm of the length), the modifiers are not, and rbegin/rend become constexpr in C++17 (std::reverse_iterator). The run-time path of the searches and of compare is a loop over std::char_traits (memchr, memcmp and their wide twins); only a compiler that has neither __builtin_is_constant_evaluated nor __builtin_constant_p (Clang before 9) takes the recursion at run time too.

Without exceptions (-fno-exceptions) the header still compiles: a call that would throw std::out_of_range (at, substr, copy, the compare overloads with a position) calls std::terminate, and operator<< sets the badbit without catching anything.

Note
The view does not manage the lifetime of the characters it refers to. Using a view whose characters have been destroyed is undefined behavior.
