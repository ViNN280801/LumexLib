Detailed Description

The MSVC backend: the _InterlockedCompareExchange128 intrinsic.

_InterlockedCompareExchange128 (destination, exchange_high, exchange_low, comparand_result) compares the 16 bytes at destination (16-byte aligned) with the pair at comparand_result (low half first), stores the exchange pair on equality and returns nonzero, and otherwise overwrites comparand_result with the value it found and returns zero. The pair at comparand_result is overwritten on success as well (with the value that was compared, which is the expected one), so this wrapper copies the expected value into a local array and returns that array as the observed value. The intrinsic is a full barrier on x64.

Status: this wrapper is compile-checked and run against a stand-in of the intrinsic on Linux (the tests substitute an <intrin.h> whose function is implemented with lock cmpxchg16b, so the order of the arguments, the halves and the result are exercised), but it has not been run with the real compiler. Run the dwcas suites on MSVC before relying on it.

This file is only meant to be included when LUMEX_DWCAS_BACKEND is LUMEX_DWCAS_BACKEND_MSVC.
