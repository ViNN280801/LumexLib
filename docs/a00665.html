Detailed Description

XmlWriterStream, an IXmlWriter that writes to a narrow or a wide standard output stream.

A narrow stream receives the bytes as they are. A wide stream receives them as wchar_t units, so the output must be in the wchar_t encoding; XmlDocument::save and XmlNode::print use encoding_wchar for wide streams. The writer does not own the stream. Consumers include the file through lumex/xml/LumexXml.
