Detailed Description

Counters of the domain, for tests and diagnostics.

All values are snapshots of relaxed counters. records is the number of hazard slots ever created (they are never freed), pooled_records the number that sit in the shared pool (not counting the per-thread caches), retired and reclaimed the number of nodes ever handed to the domain (retire_node, and reclaim_or_retire, also when it reclaims at once) and reclaimed, and passes the number of reclamation passes that took at least one node.
