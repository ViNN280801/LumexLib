Detailed Description

A bidirectional iterator for traversing direct child nodes of an XmlNode.

This iterator allows standard C++ algorithm usage and range-based for loops over a node's children. It wraps an XmlNode object (m_wrap) and keeps a reference to its parent for reverse iteration and boundary checks.

Note
The iterator holds a mutable XmlNode to allow its internal pointer to be updated during traversal (operator++, operator--).
