Detailed Description

X-macro system that generates a scoped enum together with its own compile-time reflection data and a toString() function.

LUMEX_DEFINE_REFLECTED_ENUM(EnumName, UnderlyingType, (A), (B, 5), (C)) expands to an enum class EnumName : UnderlyingType { A, B = 5, C }; plus four constexpr companions declared right next to it - EnumNameValues (a std::array of every enumerator, in declaration order), EnumNameFirst, EnumNameSize, and EnumNameLast - and a toString(EnumName) function.
