Detailed Description

Cross-platform crash dump handler with comprehensive debugging support.

This class provides a robust, thread-safe crash dump handler that automatically captures memory dumps when crashes occur on both Windows and UNIX platforms. It supports multiple dump types through the dump_factory pattern and provides comprehensive debugging information for post-mortem analysis.

The core_dump_generator offers:

  • Automatic crash detection and dump generation
  • Cross-platform compatibility (Windows/UNIX)
  • Multiple dump types and configurations
  • Thread-safe singleton pattern implementation
  • Comprehensive error handling and logging
  • Security-focused path validation
  • Atomic file operations to prevent race conditions
Invariant
The singleton instance is created only once and is thread-safe
All file operations are atomic to prevent TOCTOU race conditions
All input paths are validated for security vulnerabilities
Platform-specific handlers are properly initialized
Note
Thread safety: This class is thread-safe. Multiple threads can call public methods concurrently without external synchronization.
Exception safety: All public methods provide strong exception safety guarantee unless otherwise specified. Methods marked noexcept provide no-throw guarantee.

Version 1.0

◆ get_memory_filters_range()

static memory_filters_range_t lumex::core::utility::dump::core_dump_generator::get_memory_filters_range ( )
inlinestaticnoexcept

Get all memory filters as a range.

The view is formed while s_mutex is held, the mutex that initialize () and set_dump_type () hold while they replace the configuration, so it is made from a complete configuration and never from a half-assigned one. The mutex does not extend over the walk: the view does not own the filters.

Returns
Range of memory filters, memory_filters_range_t; it has begin (), end (), empty () and size () in every standard
Note
This method is thread-safe
The range views the filter list of the current configuration and is valid until that configuration is replaced: set_dump_type () drops the filters, so do not keep the range across a call of it, and do not walk it while another thread calls it.

inlinestaticnoexcept

Sets the admin group name used by is_admin_privileges() on UNIX.

LumexLib does not hardcode an admin group: the name defaults to empty, which leaves the root-only check in place. Passing a non-empty name makes members of that group count as admin too. A name that cannot be resolved with getgrnam() also falls back to the root-only check. On Windows this is a no-op.

Parameters
nameGroup name to treat as admin; empty disables the group check.
