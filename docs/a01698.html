Converts a double-precision floating-point number to an XPath string representation.

This function converts a double value into its canonical XPath string form. It handles special values like NaN, positive/negative infinity, and formats numbers without unnecessary leading/trailing zeroes or decimal points when representing integers.

Parameters
valueThe double value to convert.
allocA pointer to the XPathAllocator to use for allocating the string buffer.
Returns
An XPathString representing the number's string value, or an empty XPathString on allocation failure.

XPathString lumex::xml::xpath::string::string_value ( node::XPathNode const & node,
XPathAllocator * alloc )

Retrieves the string value of an XPath node.

This function extracts the string value of a given XPathNode according to XPath 1.0 rules. For element nodes, it concatenates the text content of the node and all its descendant text nodes. For attributes, comments, and processing instructions, it returns their respective values.

Parameters
nodeThe XPathNode (element, attribute, etc.) from which to get the string value.
allocA pointer to the XPathAllocator to use for accumulating string data if concatenation or copying is necessary.
Returns
An XPathString representing the string value of the node.
