template<typename Struct>
nlohmann::json lumex::core::reflection::field_reflection::to_json ( Struct const & obj)
inline

Serializes a simple aggregate to JSON, visiting every field.

Rule per field:

  • a type with has_value() and unary * is written only if has_value() is true;
  • everything else is always written.
    Template Parameters
    StructA simple standard-layout aggregate (no user constructors, no private or protected members, no base classes, no virtual functions), at most 32 fields.
    Parameters
    objThe aggregate instance to serialize.
    Returns
    A nlohmann::json object with one key per written field, named after the field.
