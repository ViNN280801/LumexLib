Detailed Description

template<class T>
class lumex::core::smart_ptr::detail::block_allocator< T >

The allocator of control blocks that no allocator was given for.

A minimal C++11 allocator: stateless, always equal, no construct/destroy of its own (the allocator_traits defaults place the object with ::new, as make_shared is specified to do). The block and the object of make_shared are one allocation of block_allocator.
