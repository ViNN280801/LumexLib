◆ ~lock_free_cell()

template<typename Pointer, typename Reclaim>
lumex::core::atomic::smart_ptr::table_wait::Detail::lock_free_cell< Pointer, Reclaim >::~lock_free_cell ( )
inline

Destroys the last box at once: nobody uses the object any more. With the immediate policy, a box this cell had to retire (a reader named it at that moment) is reclaimed by a pass of the hazard domain before the destructor returns, so everything the cell ever held is destroyed when the cell is, as with the other engines; no reader names those boxes any more, because none may be inside an operation of a destroyed object.
