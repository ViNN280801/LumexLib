Detailed Description

Serial port module: lists serial ports with device details, turns a configuration-style port name into the path the platform opens, probes a port for a device response in bounded time, and finds the process that holds a port open.

Link lumex::serial (compiled library). Works from C++11. The umbrella includes enumeration/LumexSerialPortEnumeration.hpp, port/LumexSerialPort.hpp, probe/LumexSerialProber.hpp and resolver/LumexPortProcessResolver.hpp.
