Detailed Description

The result of a three-way comparison that may leave two values unordered (NaN against anything): less, equivalent, greater or unordered.

The category of the floating-point <=>. Same values and comparisons as std::partial_ordering; unordered is neither less, equal nor greater, so unordered == 0, unordered < 0, unordered > 0, unordered <= 0 and unordered >= 0 are all false and unordered != 0 is true. There is no default constructor; take one of the named values.
