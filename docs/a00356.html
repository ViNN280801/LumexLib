Detailed Description

C++11 lightweight, non-owning view over character sequences.

This header provides a manual implementation of a string_view equivalent for C++11, offering a safe and efficient way to refer to string data without owning or copying it. It is designed to be similar in API and behavior to std::string_view introduced in C++17. The implementation is cross-platform (Windows / Linux / macOS) and relies solely on the C++11 standard library. It respects exception-safety, thread-safety (concurrent read-only access), and does not perform dynamic allocation.

Note
This LumexStringView class does not manage the lifetime of the character data it views. It is the user's responsibility to ensure that the underlying character sequence outlives the LumexStringView instance. Using a LumexStringView that refers to destroyed or out-of-scope data will lead to undefined behavior.
