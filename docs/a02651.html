Detailed Description

template<typename ErrorType>
class lumex::core::expected::error::unexpected< ErrorType >

Wrapper that holds an error value for expected.

Used to construct an expected in the error state. Analogue of std::unexpected from C++23.

Template Parameters
ErrorTypeType of the stored error value: an object type that is not an array, not cv-qualified and not a specialization of unexpected.
Note
An unexpected object is always in the error state.
