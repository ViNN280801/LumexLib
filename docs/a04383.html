Detailed Description

The function object that returns its argument unchanged, as the same reference (the counterpart of std::identity, C++20).

identity () (value) has the type T && for an argument of type T: an lvalue stays an lvalue, an rvalue stays an rvalue, nothing is copied or moved. It is the default projection of an algorithm that takes one.
