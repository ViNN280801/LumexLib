Detailed Description

template<typename T, typename U>
struct lumex::core::utility::numeric::three_way_comparison_result< T, U >

Metafunction for the three-way comparison result type.

Template Parameters
TFirst type to compare
USecond type to compare

Picks the most suitable ordering type for three-way comparison. Returns strong_ordering_t for integer types, partial_ordering_t for floating-point. strong_ordering_t and partial_ordering_t are the classes of LumexOrdering.hpp in every standard (they convert to the std:: ones from C++20).
