Detailed Description

XmlCleaner, a scope guard that frees a pointer with a given deleter function unless it is released.

The module's implementation uses it to free a temporary resource on every return path, for example an open FILE, a loading buffer or a query implementation, and calls release() once ownership has passed elsewhere. Header-only.
