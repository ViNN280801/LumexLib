Detailed Description

The holder of an alias that the engine of atomic_weak_ptr cannot pack: it owns one WEAK reference to another block and the stored pointer.

The twin of ctl_holder for weak pointers: create takes a weak reference on owner (add_weak), disposing the holder drops it (release_weak), so the holder keeps the owner's block, not its object. The holder's own counters are used like those of ctl_holder: the atomic object owns one strong reference to the holder, readers tick it and settle on its strong group.
