Detailed Description

A high-resolution stopwatch for measuring elapsed wall-clock time.

Wraps std::chrono::high_resolution_clock behind a small start/stop/elapsed interface. A single lumex_timer instance is meant to be started and stopped from one thread at a time; it is not internally synchronized.

Example
The snippet below shows the intended use.
lumex_timer timer;
timer.start_timer();
doSomeWork();
timer.stop_timer();
std::cout << "Elapsed: " << timer.elapsed_time_ms() << "ms" << std::endl;

long long lumex::core::time::timer::lumex_timer::elapsed_time_ms ( ) const

Returns the elapsed time between the last start_timer()/stop_timer() pair.

Returns
Elapsed time in milliseconds. Zero if the timer was never started/stopped.
Note
Call stop_timer() before calling this function for a stable result; calling it while the timer is still running returns the elapsed time up to the previous stop_timer() call (or zero, if it was never stopped).
