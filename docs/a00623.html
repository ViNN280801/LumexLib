Counts the leading zero bits of an unsigned integer (C++11).

Analogue of C++20 std::countl_zero for an unsigned integer of 1, 2, 4 or 8 bytes. bool and wider types, including unsigned __int128, are not in the overload set: the intrinsics below scan 32 or 64 bits, and a wider value would be truncated. A zero value returns the bit width. The function is not constexpr: the MSVC intrinsics are not constant expressions on the toolchains this library supports.

Template Parameters
NumericTypeUnsigned integer, not bool, of 1, 2, 4 or 8 bytes.
Parameters

Returns
The number of consecutive zero bits from the most significant bit, in the range 0 .. sizeof(NumericType) * 8.

Thread-safety: yes, no shared state is used.
