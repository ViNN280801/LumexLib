template<class T, int Tag, bool = std::is_empty<T>::value && !is_final_class<T>::value>
class lumex::core::smart_ptr::detail::ebo_member< T, Tag, bool >

Stores a T that is usually empty (a deleter, an allocator).

The primary template holds a member. The specialization for an empty, non-final T derives from it privately, so the member takes no space.
