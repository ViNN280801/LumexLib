Detailed Description

template<bool SwapBytes>
struct lumex::core::unicode::utf::utf16_decoder< SwapBytes >

Decoder of a UTF-16 buffer.

process (data, size, result, traits) walks size 16-bit units and calls Traits::low for a unit outside the surrogate range and Traits::high for a valid surrogate pair, threading result through the calls and returning its final value. An unpaired surrogate is skipped. With SwapBytes set, every unit is byte swapped first, to read a UTF-16 buffer of the other byte order.

Template Parameters
SwapBytesSwap the bytes of every unit before decoding.
