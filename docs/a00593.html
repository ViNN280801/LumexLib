Detailed Description

XPathLexerString, the begin and end of a token inside the text of an XPath expression.

The view does not own its characters and is not terminated. The parser compares it with null-terminated names (axes, node types, functions) through operator==, and copies it with XPathParser::alloc_string when the text must be kept. The file is internal to the XPath engine.
