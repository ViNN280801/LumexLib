Detailed Description

template<class CharT, class Traits>
class lumex::core::string_view::view::lumex_basic_string_view< CharT, Traits >

A lightweight, non-owning view over a contiguous sequence of characters; the equivalent of std::basic_string_view from C++11.

The view holds a pointer and a length. It is immutable (the characters cannot be changed through it, only the bounds of the view), cheap to copy (trivially copyable) and never allocates. The API is the one of std::basic_string_view of the newest standard, with these differences:

  • a nullptr C string gives an empty view (the standard leaves it undefined) and remove_prefix/remove_suffix clamp to the size;
  • contains, the range constructor and operator<=> are available below the standard that added them (see the header for the iterator-pair constructor);
  • clear(), to_string() and the conversion to std::basic_string are additions of the library;
  • the constructor from a std::basic_string is implicit, as std::string converts to std::string_view.
Template Parameters
CharTThe character type.
TraitsThe character traits; Traits::char_type is CharT.
Warning
The view does not own the characters. Dangling views are undefined behavior.

Views a contiguous range (explicit; C++23 constructor, here from C++11).

Accepts a type with data() and size() whose elements are CharT, such as std::vector<char>, std::array<char, N> or a span of characters. A type that converts implicitly to the view or to a pointer to characters, and one whose traits_type differs, is not accepted; a type that converts only to a std::basic_string is accepted (as in C++23). The view refers to the range: it must outlive the view.
