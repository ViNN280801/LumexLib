Detailed Description

template<typename T, typename E>
struct lumex::core::expected::result::detail::storage::expected_storage< T, E >

has_val and the union of [expected.object.general], the constructors that start one alternative, and the algorithms that move contents between two storages.

has_val is a has_val_flag as wide as the alignment of the union, so the storage has no tail padding (see there).

Template Parameters
TValue type as written (possibly const, Unit for void).
EError type.

Copies or moves the alternative of another storage of the same type: [expected.object.cons]/6 and /12.

The flag is copied as a bool (one byte), not as the has_val_flag (its whole size, padding included): the source was just built with a one-byte store, and a wider load would wait for it.
