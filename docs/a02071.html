Detailed Description

template<class T, class Allocator = std::allocator<T>>
template<bool IsConst>
class lumex::core::circular_buffer::circular_buffer< T, Allocator >::basic_iterator< IsConst >

Random-access iterator over the logical element sequence.

iterator and const_iterator are the two instances of this template. The iterator walks the buffer elements with random access, like a pointer or an iterator of std::vector; const_iterator cannot modify elements. An iterator converts to a const_iterator, and the two compare with each other in both directions.
