Detailed Description

The switch of the precondition checks of span: the macro LUMEX_SPAN_CHECKS and the macro LUMEX_SPAN_CHECKED that the members use.

The preconditions of std::span (an index below size (), front and back of a span that is not empty, first, last and subspan within the size, a count equal to a static extent, [span.cons], [span.sub], [span.elem]) are checked when LUMEX_SPAN_CHECKS is 1 and are not checked when it is 0. A violated check calls the handler of this header, detail::check_failed, which prints LUMEX_SPAN_CHECKS: <condition> failed at <file>:<line> to standard error and calls std::abort, in every build mode. The handler is an inline function of this header, so the module has no link dependency. With the checks off the members are the code they were before the checks existed.

An expression, so that it can stand in a return of a C++11 constexpr function and in a mem-initializer. In a constant expression a true condition adds nothing and a false one is not a constant expression (the handler is not constexpr): the compiler rejects the program. The condition is evaluated once, or not at all when the checks are off; it may not have a comma outside parentheses. The expression after the condition may.

◆ LUMEX_SPAN_CHECKS

#define LUMEX_SPAN_CHECKS   1

1 when the preconditions of span are checked, 0 when they are not.

The default is 1 when NDEBUG is not defined and 0 when it is. A program may define the macro as 0 or 1 before the first include of the library (-DLUMEX_SPAN_CHECKS=1 keeps the checks in a release build). Every translation unit of one program must see the same value: the members of span are inline templates, and two units that differ would hand the linker two bodies of one function (MSVC reports a mismatch at link time through detect_mismatch in the translation units of a program; the compiled modules of LumexLib do not record the value, see LUMEX_SPAN_NO_MISMATCH_GUARD; GCC and Clang do not detect it). A violated check calls the inline handler of this header: it needs nothing to link.
