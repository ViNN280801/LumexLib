Detailed Description

Contracts module: LUMEX_CONTRACT_ASSERT, the contract assertion of C++26 (P2900) from C++11 on, with the violation handler and the types that describe a violation.

Link lumex::contracts (a compiled library; the macros are header-only, the handler slot and the default handler are compiled). Works from C++11. LUMEX_CONTRACT_ASSERT (predicate); checks the predicate with the evaluation semantic of the build (ignore, observe, enforce, quick_enforce or the compiler's own contract_assert; default enforce), chosen by the CMake option LUMEX_CONTRACTS_SEMANTIC or per translation unit by the macro LUMEX_CONTRACTS_SEMANTIC. A false predicate is reported to the handler installed with set_violation_handler as a contract_violation (comment, source_location, kind, semantic, detection mode, as in <contracts> of C++26). The names are in lumex::core::contracts; only the LUMEX_CONTRACT_ASSERT* and LUMEX_CONTRACTS_* macros are global. The umbrella includes assert/LumexContractsAssert.hpp (the macros), handler/LumexContractsHandler.hpp (the handler), violation/LumexContractsViolation.hpp (contract_violation and its enumerations) and location/LumexContractsSourceLocation.hpp (source_location).
