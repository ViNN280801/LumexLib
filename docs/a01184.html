Detailed Description

Internal transport seam of the serial prober: the operations the probe engine performs on one port.

Not part of the public API. The header is header-only so the engine and the test doubles compile against it without exported symbols; the platform transports live in LumexSerialProber.cpp. Consumers must not include this header.
