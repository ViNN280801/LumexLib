Separator const & separator )

Streams every element of range with operator<<, separated by separator (C++11 to C++17).

Same contract as the C++20 overload: one pass, no trailing separator, empty text for an empty range.

Template Parameters
RangeAnything a range-based for accepts: a container, a C array, a std::initializer_list.
SeparatorAnything operator<< can write.
Parameters
rangeThe elements; each must support operator<<.
separatorWritten between (not after) elements.
Note
O(n) time, one pass. Takes part in overload resolution only when Range is iterable with streamable elements and Separator is streamable (lumex::core::utility::traits).
