Detailed Description

template<typename ErrorType>
class lumex::core::expected::result::expected< void, ErrorType >

expected specialization when the success value is absent (void).

See also
https://eel.is/c++draft/expected.void

Lets expected be used for functions that either succeed without returning a value, or return an error. It is the analogue of std::expected<void, E> from C++23.

Template Parameters
ErrorTypeError type.
Note
Here has_value() means success without a returned value, and !has_value() means the object holds an error.
The storage is the one of the primary template with the empty class Unit as the value (so the copy and move constructors, the assignments and the destructor are the ones of [expected.void.cons], [expected.void.assign] and [expected.void.dtor]: deleted, left out or trivial by the properties of ErrorType alone). Works from C++11; the table of what is constexpr in each standard is at the class expected in Expected.hpp.
