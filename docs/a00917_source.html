604// ====================== INVOKE ====================== //

606// Calls `fn (args...)` or, for a pointer to a member, applies it to the
607// first argument: the standard INVOKE.
608// The overloads below give the same result as `std::invoke` for a
609// function object, a pointer to a member function or to a data member, and an
610// object, a `std::reference_wrapper` or a pointer-like object as the first
611// argument. They are the implementation in every standard (not `std::invoke`
612// from C++17) because they are `constexpr` from C++11, while `std::invoke` is
613// `constexpr` only from C++20, and the monadic operations of `expected` are
614// `constexpr` as the standard declares them.
