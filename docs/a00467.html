Detailed Description

The global names of the optional module: optional, nullopt, make_optional and lumex_bad_optional_access.

opt/LumexOptional.hpp declares the types in lumex::core::optional::opt and puts nothing at global scope. The umbrella lumex/core/optional/LumexOptional includes this header on top of it, so a file that includes the umbrella can write optional<int> and nullopt. A header of LumexLib that needs the type but must not inject names into every file that includes it (LumexMemRead.hpp) includes opt/LumexOptional.hpp and spells the namespace out.
