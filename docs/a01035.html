Calls func(args...), catching and safely reporting any exception it throws instead of letting it propagate.

Template Parameters
FunctionCallable type; must be invocable with Args....
ArgsTypes of the arguments forwarded to func.
Parameters
excMessageMessage reported (to std::cerr) when func throws a std::exception; the exception's own what() is appended after it.
unknownExcMessageMessage reported when func throws anything that is not a std::exception (e.g. a plain int, or a type from another ABI).
funcThe callable to invoke.
argsArguments forwarded to func.
Returns
Whatever func(args...) returns on success; a value-initialized default (lumex::core::utility::traits::meta::default_return<ReturnType>::value()) if it throws.
Note
noexcept is conditional on whether the wrapped call itself is noexcept: reporting a failure is unconditionally noexcept (see detail::write_to_stderr), so it never needs to be part of this check.
Invocation intentionally uses plain func(args...), not lumex::core::utility::traits::invoke::detail::INVOKE - that helper only has a decltype-computed trailing return type (no function body) because it exists solely to drive invoke_result/ is_callable at compile time, not to be called at runtime. invoke_result_t/is_callable_v (built on top of it) remain the right tools for return-type deduction and the Callable-Named-Requirement check below.
Example
// Simple usage with default, source-location-based messages.
int result = LUMEX_SAFE_CALL(someFunction(42));
// Usage with custom messages.
int result = LUMEX_SAFE_CALL_MSG(
someFunction(42),
"Failed to execute someFunction",
"Unknown error in someFunction"
);
