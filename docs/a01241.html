Detailed Description

Operations the probe engine needs from one port.

open performs the bounded open and applies the settings. The Windows implementation runs the open on a worker thread and never blocks the caller past the deadline. write loops until every byte is out or the deadline or an error stops it. read returns as soon as at least one byte arrived (status == ok, bytes > 0); deadline_exceeded is reported only with bytes == 0; failed reports an OS error. purge flushes the input and output buffers; the engine ignores its failure.
