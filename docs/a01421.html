Detailed Description

XML module: a DOM tree of nodes, attributes and text, loading and saving with writers for files and streams, and XPath queries with variables.

Link lumex::xml (shared library). Works from C++11; the string_view_t overloads exist in every standard as inline wrappers over the exported functions: they take the lumex_string_view of lumex::string_view in every standard (a string literal, a char const * and a std::string convert to it, and from C++17 so does a std::string_view). The umbrella includes the DOM classes, the writer interface and its file and stream implementations, the parse result, the XPath classes, the common types and constants, and XmlUtils. Linking it also links lumex::unicode, whose UTF transcoders the parser and the buffer conversions use, and lumex::string_view.

The module is derived from pugixml (https://github.com/zeux/pugixml, MIT, Copyright (c) 2006-2026 Arseny Kapoulkine); its notice is in THIRD-PARTY-NOTICES.md, installed with the library.
