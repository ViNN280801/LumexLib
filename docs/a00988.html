serial_probe_result_t lumex::applied::serial::probe::detail::run_probe ( serial_transport_t & transport,
std::vector< std::uint8_t > const & request,
std::function< bool(std::vector< std::uint8_t > const &)> const & response_complete,
std::chrono::milliseconds deadline,
std::size_t max_response_bytes )
inline

Runs one bounded probe over transport.

Steps: bounded open when the transport is closed (open_timeout or open_failed stop the call); purge; write the request (io_error when it does not leave in full); read loop until the predicate confirms the response (responded), the cap is reached or the deadline expires (incomplete when bytes arrived, no_response when none did); an OS read error yields io_error with the bytes collected so far.

Parameters
transportOpen or closed port transport; the engine opens it when is_open () is false and keeps it open afterwards.
requestRequest bytes; an empty vector skips the write step.
response_completePredicate over the accumulated response, called after every read chunk and never with an empty vector.
deadlineOverall budget for open, purge, write and reads.
max_response_bytesResponse cap; values below 1 are clamped to 1.
Returns
The probe outcome with the collected bytes, the elapsed time and the formatted platform error.
