Detailed Description

template<typename T>
struct lumex::xml::utility::XmlCleaner< T >

A simple RAII (Resource Acquisition Is Initialization) wrapper for managing dynamically allocated memory.

XmlCleaner ensures that a provided memory block is deallocated using a specified deleter when the XmlCleaner object goes out of scope, unless release() is called. This is particularly useful for managing memory that might be conditionally owned or passed between functions.
