Detailed Description

template<typename It>
struct lumex::core::span::view::is_contiguous_iterator< It >

Tells whether a type is an iterator over contiguous storage.

The constructors of span that take an iterator accept a type only when this trait is true for it. Raw pointers always qualify. From C++20 the answer is std::contiguous_iterator. Before C++20 the language cannot tell a std::vector iterator from a std::deque one: the iterators of std::vector (not of std::vector<bool>), std::array, std::basic_string, std::basic_string_view, std::valarray and std::initializer_list are recognized by name in libstdc++ and libc++ (in the standard library of MSVC the iterators of std::vector, std::basic_string, std::array and std::basic_string_view, the last one as std::_String_view_iterator<Traits> when _HAS_CXX17 is set), see LumexSpanStdIterators.hpp, and any other iterator type, a user's own included, is not contiguous until it is named by a specialization:

template <> struct lumex::core::span::view::is_contiguous_iterator<my_it>
: std::true_type {};
