Detailed Description

template<class T, class Allocator = std::allocator<T>>
class lumex::core::circular_buffer::CircularBuffer< T, Allocator >::iterator

Random-access iterator over the logical element sequence.

This iterator walks CircularBuffer elements with random access. It behaves like ordinary pointers or iterators of standard containers such as std::vector.
