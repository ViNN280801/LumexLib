Detailed Description

Base64 encoder.

encode (void const *, std::size_t) and encode (std::vector<byte_type> const &) are exported and have the same signature in every C++ standard, so a consumer built at another standard than the library links. The std::string_view (C++17) and std::span (C++20) overloads are inline wrappers over the pointer and size one. The class itself is not exported: a dllimport class makes clang-cl emit an import for an inline member it does not inline, and the library does not provide the standard-dependent overload.
