Detailed Description

Provides static utility methods for time and date handling.

The lumex_time class offers a convenient, static interface for common time-related operations. It abstracts away platform-specific details and provides a consistent API for retrieving current date/time strings and timestamps in various granularities. All methods are designed to be thread-safe as they primarily involve reading system time and performing calculations without shared mutable state.

Formats a point in time as a local-time string, with a robust fallback chain.

Attempts to format time_ as local time (localtime_s on Windows, localtime_r on POSIX). If that fails, falls back to UTC (gmtime_s/gmtime_r). If that also fails, returns the raw number of seconds since the Unix epoch as a decimal string, so this method never throws and never returns an empty string.

Parameters
time_The std::time_t value to format. Defaults to the current system time.
fmtA strftime-compatible format string. Defaults to "%Y%m%d-%H%M%S".
Returns
The formatted timestamp string, or a raw epoch-seconds string as a last-resort fallback.
Note
This method is thread-safe (uses only thread-safe _r/_s time functions and local state).
Does not throw.
Example
The snippet below shows the intended use.
std::string log_stamp = lumex_time::timestamp();
std::string custom = lumex_time::timestamp(std::time(nullptr),
"%Y-%m-%d");

Formats a point in time as a local-time string with a millisecond suffix.

Uses the same fallback chain as timestamp() (local time -> UTC -> raw epoch seconds) for the seconds portion of tp, then appends a ".mmm" millisecond suffix derived from tp itself. If the fallback chain has to resort to the raw epoch-seconds string, no millisecond suffix is appended.

Parameters
tpThe std::chrono::system_clock::time_point to format. Defaults to the current time.
fmtA strftime-compatible format string, applied to the seconds portion of tp. Defaults to "%Y-%m-%d %H:%M:%S".
Returns
The formatted timestamp string with a millisecond suffix, or a raw epoch-seconds string as a last-resort fallback.
Note
This method is thread-safe.
Does not throw.
Example
The snippet below shows the intended use.
std::string log_stamp = lumex_time::timestamp_ms();
