Detailed Description

An IXmlWriter implementation that writes XML data to a C++ standard output stream.

XmlWriterStream provides a concrete implementation of the IXmlWriter interface, allowing XML serialization directly to std::ostream (for char_t streams) or std::wostream (for wchar_t streams). It handles the differences between narrow and wide character streams.

Note
This class does not own the stream; the caller is responsible for its lifetime.
