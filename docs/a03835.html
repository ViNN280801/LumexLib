The number of owners.

◆ use_count_settled()

long lumex::core::smart_ptr::detail::split_counter::use_count_settled ( ) const
inlinenoexcept

The number of owners once no owner is in transit.

Returns count at an instant at which ext is zero, waiting (a bounded busy-wait, then yields) while it is not. A word that is zero returns 0 at once. Exact apart from the lag of the decrement of a slot (the owner that a store or a compare-exchange of an atomic smart pointer has not dropped yet). It may block while a pinning thread is suspended, and it may not return while loads and stores of an atomic that holds the value keep running; it must not be called from a signal handler on a pinned thread.
