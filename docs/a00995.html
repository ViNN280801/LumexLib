Detailed Description

Internal machinery of optional: the storage union, the layers that give optional the special member functions the standard describes, an INVOKE for C++11 and the traits the converting operations use.

Everything here lives in lumex::core::optional::opt::detail and is not an interface for consumers. optional<T> holds, as its only member, the last of a chain of class templates, one layer for each special member function whose existence and triviality the standard fixes ([optional.ctor], [optional.dtor], [optional.assign]):

  • opt_destruct_base: the union { dummy, value }, the engaged flag, the in-place constructors and the destructor, trivial when T is trivially destructible ([optional.dtor]/2);
  • opt_copy_ctor_base, opt_move_ctor_base, opt_copy_assign_base, opt_move_assign_base: each defaulted (so trivial) when the standard says it is trivial, written out otherwise, and deleted in its layer when T lacks the operation, so that the defaulted member of every layer above, and of optional, is defined as deleted (a deleted copy) or deleted and then ignored by overload resolution (a move: an rvalue is copied).

C++11 has no requires and no conditionally defaulted member, so a layer per special member function is the technique of the standard libraries.

◆ LUMEX_OPTIONAL_CONSTEXPR_CXX20

#define LUMEX_OPTIONAL_CONSTEXPR_CXX20

constexpr where the language lets a constant expression start the lifetime of an object in a union (std::construct_at on an inactive member, P0784, P1330): C++20 with a constexpr of 201907L and std::construct_at; empty before.

The members that change the active member of the union (a non-trivial copy or move, assignment from a value or an optional, emplace, swap, the non-trivial reset) are marked with it. The constructors, the observers and the trivial special members are constexpr from C++11 and the trivial reset from C++14.
