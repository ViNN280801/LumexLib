Detailed Description

Lock in one 32-bit word that puts contended threads to sleep.

lock () and unlock () are const, so a const member function of the owner (such as load ()) can take the lock.

inlinenoexcept

Releases the lock and wakes the threads that sleep on it.

Release ordering. Both bits are cleared in one exchange, so the woken threads and the threads that arrive later all see a released lock without the sleeper bit.
