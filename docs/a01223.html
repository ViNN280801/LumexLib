Detailed Description

ILumexSettings over JSON files, parsed and written with the vendored nlohmann/json.

Declares LumexSettingsJSON and its Constants (the .json extension and settings, the implicit section of the scalar members of the root object). A section is a JSON object and a key is one of its scalar members. Without LUMEX_SETTINGS_WITH_JSON (the nlohmann/json header absent at build time) the class still compiles, but loading, saving and validation fail.
