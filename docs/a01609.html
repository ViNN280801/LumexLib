Finds the iterator whose (projected) value is numerically nearest to value.

Requires the range to be sorted according to pred/proj (uses std::ranges::lower_bound from C++20 and std::lower_bound below), then compares the found element and its predecessor to pick whichever is closer to value; on a tie the predecessor wins. A sentinel of another type than the iterator is walked to once, before the search.

Returns
Iterator to the nearest element, or the end iterator if first == last.
