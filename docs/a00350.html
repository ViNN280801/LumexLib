Detailed Description

Concatenates the operator<< text of any number of arguments into one std::string.

stringify("channel=", 2, " flow=", 1.5) returns "channel=2 flow=1.5". Every argument must be streamable: a C++20 concept constraint, a static_assert below C++20. Below C++20, std::unique_ptr and std::shared_ptr stream their raw address.

Nothing here is placed in the global namespace, so the names cannot clash with a consumer's own stringify. Call it qualified, or bring it in with a local using lumex::core::string::utility::stringify;.
