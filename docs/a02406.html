Specialization for floating-point types.

Template Parameters
TFirst floating-point type
USecond floating-point type

Implements safe comparison between different floating-point types. Handles special values correctly: NaN and infinities.

Note
NaN always returns false for ordered comparisons; infinities compare by sign
