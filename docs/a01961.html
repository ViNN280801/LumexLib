Detailed Description

template<typename ErrorType>
struct lumex::core::expected::result::failure_t< ErrorType >

Marker returned by failure(error): a failed call carrying an error.

The stored error does not have to match the target error type exactly - anything the target error type can be built from works, so a literal, a std::string or a richer error type can all be returned the same way. The conversion is implicit by design and removed by SFINAE when the target error type cannot be built from the stored error.

Template Parameters
ErrorTypeStored error type (decayed, never a reference).
