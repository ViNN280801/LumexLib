bool lumex::xml::xpath::utility::copy_xpath_variable ( XPathVariable * lhs,
XPathVariable const * rhs )

Copies the value of one XPath variable to another.

This function performs a deep copy of the value from rhs (source variable) to lhs (destination variable), handling different XPath variable types (node-set, number, string, boolean). It forwards to the inline lumex::xml::xpath::variable::copy_xpath_variable of XPathVariable.hpp, which holds the only implementation; this exported function is kept so that programs linked against it still find it.

Parameters
lhsA pointer to the destination XPathVariable to which the value will be copied.
rhsA constant pointer to the source XPathVariable from which the value will be copied.
Returns
true if the copy was successful, false otherwise (e.g., if memory allocation fails for node-set).
Exceptions
`LUMEX_ASSERT`if an invalid variable type is encountered.
Note
This function is typically used in XPath variable assignment or initialization scenarios.

XPathNode const * end,
XPathNodeSet::type_t type )

Retrieves the first node in document order from a range of XPath nodes.

This function efficiently finds the first XPathNode in XML document order within the specified range [begin, end). If the range is already sorted, it directly returns the first or last element. If unsorted, it performs a linear scan using std::min_element with a document order comparator.

Parameters
beginA pointer to the first XPathNode in the range.
endA pointer to one past the last XPathNode in the range.
typeThe XPathNodeSet::type_t indicating the current order of the nodes.
Returns
The XPathNode that appears first in document order, or an empty XPathNode if the range is empty.
Exceptions
`LUMEX_ASSERT`if an invalid type is provided.

Determines the current document order of a range of XPath nodes.

This function efficiently checks if a given range of XPathNodes is sorted in ascending, descending, or unsorted document order. It is an optimization to avoid unnecessary sorting.

Parameters
beginA pointer to the first XPathNode in the range.
endA pointer to one past the last XPathNode in the range.
Returns
An XPathNodeSet::type_t value indicating the order of the nodes in the range.
Note
This function performs a linear scan and is primarily used internally by xpath_sort.

XPathNode * end,
XPathNodeSet::type_t type,
bool rev )

Sorts a range of XPath nodes by document order.

This function sorts the nodes in the specified range [begin, end) according to their XML document order. It can sort in ascending or descending order. It first checks the current order using xpath_get_order to avoid redundant sorting.

Parameters
beginA pointer to the first XPathNode in the mutable range to sort.
endA pointer to one past the last XPathNode in the mutable range to sort.
typeThe current XPathNodeSet::type_t of the range before sorting.
revIf true, sort in descending document order; otherwise, ascending.
Returns
The new XPathNodeSet::type_t indicating the sorted order of the nodes.
