Detailed Description

Base64 module: encoding, decoding and syntax checks of Base64 text.

Link lumex::base64 (compiled library; it links lumex::span and lumex::string_view). Works from C++11; the span overload of the encoder (a std::span converts to it) and the string overloads are available in every standard, as inline wrappers over the exported functions. The string overloads take the lumex_string_view of lumex::string_view in every standard (a string literal, a char const * and a std::string convert to it, and from C++17 so does a std::string_view). The umbrella includes codec/Base64.hpp, decode/Decoder.hpp, encode/Encoder.hpp and validate/Validator.hpp.
