Detailed Description

Process-wide report sink for the non-throwing JSON helpers.

LumexJsonHelper never throws: it returns false, an empty document or a default value, and describes what went wrong through this sink. The library does not depend on any logging facility. A consumer installs one function pointer (set_diagnostic_reporter) to route the messages into its own logger. Without a reporter, or when the reporter throws, warning and error messages go to std::cerr and debug and info messages are dropped.

The module is header-only, so the reporter lives in a LumexCallbackSlot instantiated by every binary that includes this header. On Windows each executable or shared library has its own slot: install the reporter from the binary that calls the helpers.
