Detailed Description

Unicode module: transcoding policies for UTF-8, UTF-16, UTF-32, Latin-1 and wchar_t, and the string conversions to_utf8 and to_wide.

Link lumex::unicode (header-only). Works from C++11. The umbrella includes utf/LumexUtf.hpp (counters, writers and decoders in lumex::core::unicode::utf) and convert/LumexUnicodeConvert.hpp (lumex::core::unicode::convert). The conversions do not depend on the C locale or the operating system. The code comes from the XML module: the functions are Lumex's own, the structure of the policy classes is taken from pugixml; see THIRD-PARTY-NOTICES.md.
