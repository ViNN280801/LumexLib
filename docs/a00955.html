◆ LumexSettingsCreateFn

using lumex::applied::settings::guard::LumexSettingsCreateFn = std::function<bool (void)>

Callback that (re)creates a settings file's default content from scratch.

Invoked when the guarded file is missing, unreadable, or fails the underlying ILumexSettings::load() call. A typical implementation populates a fresh ILumexSettings instance with an application's default key/value pairs and persists them via save() to the same path the guard was constructed with.

Returns
true if defaults were written successfully, false otherwise.

◆ LumexSettingsValidateFn

using lumex::applied::settings::guard::LumexSettingsValidateFn = std::function<bool (std::string const &)>

Validation callback for a single settings key.

Receives the key's current raw string value, exactly as returned by ILumexSettings::get(), and returns true if that value is acceptable as-is, false if it must be overwritten with the key's configured default.

Note
Must not throw; if it does, LumexSettingsGuard catches the exception and treats it the same as returning false (value rejected, default restored).
