Detailed Description

Internal implementation structure for XPathQuery.

This struct holds the core components of a compiled XPath query, including the root of the Abstract Syntax Tree (AST), the memory allocator used for AST nodes, and a flag for out-of-memory conditions. It is managed by XPathQuery via an opaque pointer.

Note
This separation of interface (XPathQuery) from implementation (XPathQueryImpl) is a Pimpl (Pointer to Implementation) idiom, often used to hide implementation details, reduce compile-time dependencies, and provide binary compatibility.
