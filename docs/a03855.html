◆ disown()

void lumex::core::smart_ptr::detail::ctl_holder::disown ( )
inlinenoexcept

Gives up the reference on the owner: whoever drops (or hands over) the unit of the atomic word that installed the holder also drops (or hands over) that reference, so that the owner's use_count () does not carry a reference of a holder that only the pins of replaced words keep alive. Call it at most once, from the thread that owns the word's unit and before it releases that unit: the release orders the write before the disposal of the holder.
