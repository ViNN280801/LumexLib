Detailed Description

Base64 syntax check: the validator class of the lumex::base64 library.

validator::is_valid_base64() tells whether text is well-formed Base64 without decoding it: alphabet characters followed by at most two =, with or without padding. The pointer and size overload is compiled into the library and has the same signature in every C++ standard; the string overload is an inline wrapper over it (it takes the lumex_string_view of lumex::string_view in every standard; a std::string_view converts to it). Like the other Base64 headers, it brings the names of the codec's Types namespace into the global namespace with a using-directive.
