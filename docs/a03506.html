Detailed Description

Exception thrown when attempting to access the value of an empty optional.

This exception class is derived from std::logic_error and is thrown by the value() method of optional if has_value() is false. It indicates a programming error where an attempt was made to dereference an optional object that does not currently hold a value.

Note
It derives from std::logic_error, not from std::bad_optional_access: that class exists only from C++17 and the module works from C++11, so one exception type serves every standard. Code that catches std::bad_optional_access does not catch it; catch std::logic_error or this class. The std::string constructor is the reason for including <string> here (the header does not rely on <stdexcept> to bring it).
