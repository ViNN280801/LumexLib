Detailed Description

downcast(), a checked dynamic_cast from a polymorphic base to a derived class that throws bad_down_cast on a type mismatch, and the non-throwing downcast_noexcept().

Works from C++11. The constraints accept only a real downcast: pointer to pointer or lvalue reference to lvalue reference, complete class types, a polymorphic source, a target derived from the source through a public and unambiguous base (or the same class) and no loss of cv-qualifiers. Any other use finds no overload (SFINAE, the same std::enable_if form in every standard), so it can be detected and never fails inside the body. A null pointer converts to a null pointer without an error. bad_down_cast derives from std::bad_cast and names both types in its message.
