Detailed Description

Serial port settings applied when the port is opened.

The defaults match the common instrument configuration (9600 baud, 8 data bits, no parity, one stop bit, no flow control). A combination the current platform cannot configure (for example 1.5 stop bits outside Windows) makes open fail with open_failed and an explanatory system_error; no exception is thrown.
