Definition LumexIndexSequence.hpp:147

The list 0, 1, ..., Count - 1 of type T (the counterpart of std::make_integer_sequence, C++14).

A negative count and a count above 16384 are refused: the alias has no type then, so make_index_sequence<N - 1> with N == 0 is an error at once instead of a compiler running out of memory on a list of 2^64 integers (a negative count converts to a huge unsigned one).
