Detailed Description

lumex_wstring_view: the view over wchar_t, the std::wstring_view of the library from C++11.

A header-only alias of lumex_basic_string_view<wchar_t> (see LumexBasicStringView.hpp for the class). The global alias lumex_wstring_view is the wide view type of the whole library in every C++ standard.
