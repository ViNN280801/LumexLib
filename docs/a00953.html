Detailed Description

Base64 encoding: the encoder class of the lumex::base64 library.

encoder::encode() turns bytes into Base64 text in the standard alphabet (with + and /), padded with = to a multiple of four characters. The pointer and size overload and the std::vector overload are compiled into the library and have the same signature in every C++ standard; the overload for lumex::core::span::view::span (every standard; a std::span converts to it) and the string overload (lumex_string_view in every standard; a std::string_view converts to it) are inline wrappers over the pointer one. Like the other Base64 headers, it brings the names of the codec's Types namespace (byte_type, string_type_t) into the global namespace with a using-directive.
