◆ hash_round()

std::uint64_t lumex::core::string_view::view::detail::hash_round ( std::uint64_t acc,
std::uint64_t block )
inlinenoexcept

The hash of the characters of a view: the same value in every C++ standard, with every compiler and standard library.

A 64-bit block hash (the rounds of xxHash64 over 8-byte blocks and the finalizer of MurmurHash3), the length is mixed in, so a string and the same string followed by NULs differ. It is not the hash of std::hash<std::basic_string_view> (whose value is the choice of the standard library and changes with it): a library built at C++11 and a program built at C++17 must hash a key alike.

What is hashed: for one-byte characters (char, char8_t) the bytes, read eight at a time as little-endian integers (so a big-endian machine gives the same value, through a byte swap); for wider characters (wchar_t, char16_t, char32_t) the code unit values, each zero-extended to 32 bits and two of them packed into one block (so strings of equal code UNIT sequences hash alike: wchar_t of 2 bytes (Windows) and of 4 bytes, and char16_t and char32_t for text inside the Basic Multilingual Plane; a character outside it is two units in UTF-16 and one in UTF-32 and hashes differently; a unit above 2^32 is reduced modulo 2^32). The value is a 64-bit one; on a 32-bit platform size_t takes its low 32 bits.
