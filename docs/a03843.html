Detailed Description

template<class P, class D, class A>
class lumex::core::smart_ptr::detail::ctl_ptr< P, D, A >

A control block over a pointer, a deleter and an allocator.

Template Parameters
PThe managed pointer type: Y * or std::nullptr_t.
DThe deleter type; d (p) is called when the strong group ends.
AThe allocator type the block was allocated with.
