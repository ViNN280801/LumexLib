Detailed Description

lumex_string_view: the view over char, the std::string_view of the library from C++11.

A header-only alias of lumex_basic_string_view<char> (see LumexBasicStringView.hpp for the class). The global alias lumex_string_view is the view type of the whole library in every C++ standard: a module with a string overload takes it by value below C++17 and std::string_view converts to it implicitly from C++17.
