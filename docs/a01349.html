Detailed Description

template<typename T>
class lumex::core::atomic::smart_ptr::lock_based_table_wait::atomic_weak_ptr< T >

Atomic std::weak_ptr<T>, as std::atomic<std::weak_ptr<T>>.

Every member function may be called concurrently with any other on the same object, except the constructors and the destructor. The object holds a weak reference only: it keeps the control block, not the managed object, alive.

template<typename T>

std::memory_order order = std::memory_order_seq_cst ) const
inlinenoexcept

Blocks while the stored value is equivalent to old.

Returns at once if the stored value is not equivalent to old. Otherwise sleeps until notify_one or notify_all wakes it and checks again. The comparison locks both weak pointers for a moment; it keeps no owner while the thread sleeps.

Parameters
oldThe value the caller last saw.
orderrelaxed, consume, acquire or seq_cst.
