Detailed Description

Abstract base class for implementing custom XML tree traversal logic.

XmlTreeWalker defines a customizable interface for walking an XML document tree. Users can derive from this class and override begin, for_each, and end methods to implement specific behaviors during traversal, such as filtering nodes, collecting data, or performing modifications.

Note
This class is intended to be used with XmlNode::traverse().
See also
XmlNode::traverse()
