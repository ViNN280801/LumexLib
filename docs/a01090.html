template<typename Object>
XmlDocumentBase & lumex::xml::document::get_document ( Object const * object)
inline

Retrieves a reference to the XmlDocumentBase object that owns a given object (node or attribute).

Template Parameters
ObjectThe type of the object (e.g., XmlNodeBase, XmlAttributeBase).
Parameters
[in]objectA pointer to the object whose owning document is to be retrieved. Must not be nullptr.
Returns
A reference to the XmlDocumentBase that manages the memory for object.

This function works by accessing the XmlMemoryPage associated with object and then retrieving the allocator (which is the XmlDocumentBase itself) from that page.

Note
This is an internal utility function, primarily used for memory management and ownership checks.
Exceptions
`LUMEX_ASSERT`if object is nullptr (debug builds only).
