Detailed Description

Describes a single settings key that LumexSettingsGuard::ensureKeysWithDefaults must keep present and valid.

Section, key, default value and an optional validator, in the flat string-value model of ILumexSettings. The interface cannot tell "key absent" from "key present with an empty value" - get() returns an empty string for both - so both states are treated identically here: a key needs its default whenever validate rejects its current value or, when no validate is supplied, whenever that value is an empty string.
