Detailed Description

template<typename T, typename U>
struct lumex::core::utility::numeric::comparison_traits< T, U >

Metafunction describing comparison traits of two types.

Template Parameters
TFirst type to compare
USecond type to compare

Provides compile-time type information used to optimize comparison algorithms. Uses STL common_type to pick a common conversion type.

Note
All computation is compile-time and does not affect runtime performance
