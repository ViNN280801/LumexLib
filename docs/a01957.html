Detailed Description

Marker returned by success(): a successful call with no value.

Converts into Expected<void, ErrorType> (success without a value) or into Expected<Target, ErrorType> when Target is default-constructible; the void success type is what keeps the two conversions from competing.

Note
Stateless: it carries no data.
