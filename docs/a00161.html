Detailed Description

Text parsers for Linux /proc/<pid> files, the executable name rules and the process tree rules of LumexProcessMonitor.

Pure functions on text and on lists of process links, so they work, and are tested, on any platform; the monitor applies the Linux ones on Linux and the Windows one on Windows.
