Detailed Description

Format-agnostic backup/repair/validation layer built on top of ILumexSettings.

Keeps a settings file usable: restores default keys, backs up and regenerates a corrupted file, and validates single keys. It works with any ILumexSettings implementation (INI, JSON, XML or one of your own) because it drives everything through the interface's load/save/get/add contract instead of a concrete parser.
