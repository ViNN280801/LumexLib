Detailed Description

template<typename T, typename Cell>
class lumex::core::atomic::smart_ptr::table_wait::Detail::basic_atomic_shared_ptr< T, Cell >

Atomic std::shared_ptr<T>, as std::atomic<std::shared_ptr<T>>.

Every member function may be called concurrently with any other on the same object, except the constructors and the destructor. Two shared pointers are equivalent when they store the same pointer and either share ownership or are both empty; compare_exchange_* and wait compare that way.

Template Parameters
TThe element type of the shared pointer (may be incomplete, void or const; an array type from C++17 on).
CellThe engine: lock_based_cell, lock_free_cell or std_backed_cell of std::shared_ptr<T>.

Blocks while the stored value is equivalent to old.

Returns at once if the stored value is not equivalent to old. Otherwise sleeps until notify_one or notify_all wakes it and checks again; a wake-up that finds an equivalent value sleeps again.

Parameters
oldThe value the caller last saw.
orderrelaxed, consume, acquire or seq_cst.
