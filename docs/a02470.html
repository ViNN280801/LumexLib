Detailed Description

Base of every bad_expected_access<ErrorType>: catch it to handle the failed value() of any expected without naming the error type.

Analogue of std::bad_expected_access<void> from C++23. It holds no error and cannot be constructed by itself (its constructors are protected); what() is defined here.
