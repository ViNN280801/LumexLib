Detailed Description

template<typename T>
class lumex::core::optional::opt::optional< T >

A C++11 implementation of std::optional for type-safe nullable values.

An optional either holds a T or is empty. The value lives in a union member next to a bool, so there is no allocation and sizeof is that of std::optional<T>. The special member functions are those of [optional.ctor], [optional.dtor] and [optional.assign]: trivial when the ones of T are, deleted when T cannot be copied (or, for the moves, ignored by overload resolution when T cannot be moved), and written out otherwise. After a move the source still holds its moved-from value.

Template Parameters
TThe type of the value to be held: an object type that is not an array, in_place_t or nullopt_t.
