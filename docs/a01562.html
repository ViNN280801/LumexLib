◆ get_deleter()

template<class D, class T>
D * lumex::core::smart_ptr::get_deleter ( shared_ptr< T > const & p)
noexcept

A pointer to the deleter of type D that p owns, or null.

Only a deleter that was given to the constructor or to reset is found (not the implicit delete, not a make_shared block), as in the standard. A deleter that came from a shared library other than this one is not found: the type identity is per library.
