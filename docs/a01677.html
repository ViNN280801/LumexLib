◆ get_allocator()

template<typename Object>
XmlAllocator & lumex::xml::memory::get_allocator ( Object const * object)
inline

Retrieves the XmlAllocator instance that manages the memory for a given object.

Template Parameters
ObjectThe type of the object (e.g., XmlNodeBase, XmlAttributeBase, xml_mem_str_header_t).
Parameters
[in]objectA pointer to the object for which to retrieve the allocator. Must not be nullptr.
Returns
A reference to the XmlAllocator that owns object's memory.

This function determines the XmlMemoryPage that contains object and then accesses the allocator pointer stored within that page. Since each page points back to its managing allocator (which is typically the XmlDocumentBase), this provides a way to get the correct allocator for any object within an XML document.

Exceptions
`LUMEX_ASSERT`if object is nullptr (debug builds only).

This is an internal utility function.

std::size_t const lumex::xml::memory::kdefault_xml_memory_page_size = 32768 - sizeof (XmlMemoryPage)
static

Defines the default size of a memory page for XML allocation.

This constant specifies the size of the data region within an XmlMemoryPage, excluding the page's own metadata size. It is set to 32KB minus the size of XmlMemoryPage structure itself, to optimize for common system page sizes or cache lines.

Note
This value can impact performance and memory footprint. Size of the memory page
