Detailed Description

template<typename T, bool = std::is_trivially_destructible<T>::value>
struct lumex::core::optional::opt::detail::opt_destruct_base< T, bool >

The union, the flag and the destructor; this form is for a trivially destructible T, so the destructor is trivial.
