Floating-point source, integral target. The bounds are compared in long double, which is only double on MSVC: the maximum of a 64-bit target rounds up to 2^63 / 2^64 there, so the exclusive power-of-two bound 2^digits (exact in any binary floating type) is checked as well. The lowest value (0 or -2^digits) is always exact.
