Detailed Description

Internal XML parser structure responsible for tokenizing and building the XML document tree.

This structure contains the state for the XML parsing process, including the allocator, error status, and error offset. It provides core methods for parsing different XML constructs such as DOCTYPE, comments, CDATA, processing instructions, and the main element tree.

Note
This is a low-level parsing component; most users will interact with XmlDocument for parsing.
