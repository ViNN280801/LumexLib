Detailed Description

Writing policy: stores the UTF-8 bytes of each code point.

value_type is the output pointer; low, high and any write the bytes of one code point at result and return the pointer behind them. any picks low or high by the value. The buffer must hold the size a utf8_counter run over the same input returned.
