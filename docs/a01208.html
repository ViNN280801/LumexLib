Detailed Description

Hazard pointer module: hazard_pointer, hazard_pointer_obj_base and make_hazard_pointer, the interface of the C++26 <hazard_pointer> from C++11 on.

Link lumex::hazard_pointer (a compiled library; the reader side is header-only). Works from C++11. A hazard pointer protects one object that is read from an atomic pointer; a thread that removes the object from the structure calls retire on it, and the object is deleted only once no hazard pointer protects it. The classes follow [saferecl.hp] of the C++26 draft (P2530R3) with the batch functions of P3428R4 (make_hazard_pointer_batch, clear_hazard_pointer_batch). The extension clean_up () runs a reclamation pass at once. One domain serves the whole process; there are no custom domains, cohorts or executors, as in the standard.

The names are in lumex::core::hazard_pointer. The classes are the module's own on every standard and toolchain (they are not aliases of the C++26 standard ones, which no library ships yet); the API shape is the standard's. The umbrella includes base/LumexHazardPointerObjBase.hpp, holder/LumexHazardPointerHolder.hpp and holder/LumexHazardPointerBatch.hpp; the engine (slots, retired lists, reclamation) is in engine/LumexHazardPointerEngine.hpp.
