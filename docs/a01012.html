Tells the processor that the calling thread is spinning.

On x86 this is the pause instruction, which makes a spin loop cheaper for the other hardware thread of the core and for the memory bus. Other targets give up the rest of the time slice instead.

inlinenoexcept

Wakes every thread sleeping in wait_until_changed on word.

Taking and releasing the stripe mutex before the broadcast orders the change of the word before the re-check of every sleeper that has not fallen asleep yet; the broadcast wakes the ones that have.

◆ notify_one()

void lumex::core::atomic::sync::table_wait::Detail::notify_one ( std::atomic< std::uint32_t > & word)
inlinenoexcept

Wakes at least one thread sleeping in wait_until_changed on word.

The stripe is shared with other words, so a single wake-up could reach a sleeper of another word and leave the sleepers of word asleep. The call wakes the whole stripe instead.

Returns the stripe that serves the word at address.

The table is built in static storage on first use and never destroyed: a thread that still sleeps while the program exits never finds a destroyed mutex, and no destructor runs at exit.

◆ wait_until_changed()

void lumex::core::atomic::sync::table_wait::Detail::wait_until_changed ( std::atomic< std::uint32_t > const & word,
std::uint32_t old )
inlinenoexcept

Blocks the calling thread while word holds old.

The value is re-read under the stripe mutex, and the waking side changes the word before it takes that mutex, so a change made before the thread falls asleep is never missed. Returns once the word holds another value; wake-ups meant for other words of the stripe put the thread back to sleep.

Parameters
wordThe word to watch.
oldThe value the caller last saw.
