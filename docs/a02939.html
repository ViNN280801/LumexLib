Detailed Description

template<typename T>
class lumex::core::filesystem::fs::filesystem_result< T >

A generic result type for filesystem operations that encapsulates a value or an error.

This class is designed to provide exception-safe error handling for filesystem operations. Instead of throwing exceptions on failure, functions return filesystem_result<T> which explicitly indicates success or failure and holds either the successful value or an error code.

Template Parameters
TThe type of the value returned on success.
