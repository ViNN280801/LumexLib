Detailed Description

Short macros over LumexLogging: lumDebug to lumCritical, and the ...FL variants that prefix the source file and line.

Each macro takes a module name and the message parts and calls the LumexLogging function of the same level. The header also provides LUMEX_FUNCTION_NAME (the compiler's decorated name of the enclosing function) by including LumexMacros.hpp, which defines it.
