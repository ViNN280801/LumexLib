template<class T, class Source, class Filter>
bool lumex::core::hazard_pointer::hazard_pointer::try_protect ( T *& ptr,
Source const & src,
Filter filter )
inlinenodiscardnoexcept

Extension: try_protect over a source that is not a std::atomic<T *>.

Template Parameters
TThe protected object type.
SourceA callable: src () loads the shared word (with at least acquire ordering; pass seq_cst if the structure needs it) and returns it, for example a tagged pointer or an integer.
FilterA callable: filter (word) returns the T * the word stands for (the word with its tag bits removed).
Parameters
[in,out]ptrThe pointer to protect; on failure it receives filter (src ()).
[in]srcLoads the shared word.
[in]filterMaps a loaded word to the pointer.
Returns
True when filter (src ()) equals ptr after the announcement.
Precondition
The holder is not empty. T is hazard-protectable. Neither callable throws.
Note
An extension: the standard's hazard_pointer has no such overload.

Parameters

[in]srcThe source the pointer was read from.
Returns
True when src still held ptr after the announcement; the object is then protected. False: nothing is protected, ptr is the new value.
