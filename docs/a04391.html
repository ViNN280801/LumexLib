Detailed Description

The function object that compares two operands of any types with < (the counterpart of std::less<void>, C++14).

less () (left, right) is left < right with both operands forwarded, so a mixed comparison such as std::string with char const * works, and the result is whatever < returns. If both operands are pointers to objects the order is the strict total order of std::less<void const volatile *>, as the standard requires of std::less<void>. It does not take part in overload resolution when the operands cannot be compared with <.
