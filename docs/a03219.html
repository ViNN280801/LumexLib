template<class T, class D>
bool lumex::core::hazard_pointer::hazard_pointer_obj_base< T, D >::reclaim_or_retire ( D d = D ())
inlinenoexcept

Extension: reclaims the object now when no hazard pointer protects it, otherwise retires it.

Parameters
[in]dThe deleter, move-assigned to the stored one.
Returns
True when the deleter ran before the call returned; false when a hazard pointer named the object and it was retired (reclaimed once nobody protects it).
Precondition
As retire. The calling thread holds no hazard pointer that protects this object (it would keep it alive and send it down the retire path).
Note
The scan reads every hazard slot ever created, one address against all of them: cost proportional to their number, no allocation, no pass over the retired objects of other threads. The deleter runs on this thread with nothing locked, so it may use hazard pointers and retire other objects. Not in the standard's interface.
