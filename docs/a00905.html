Detailed Description

Exceptions module: the LumexBaseException hierarchy, stack traces, a crash handler that writes minidumps or core dumps, and an exception-safe call wrapper.

Link lumex::exceptions (compiled library). Works from C++11; the std::string_view constructor of LumexBaseException appears from C++17. The umbrella includes the crash handler with its default paths and the Windows SEH translator (crash/), exception/LumexException.hpp, the stack trace classes (stacktrace/) and LumexExceptionWrapper.hpp (LUMEX_SAFE_CALL and its variants).
