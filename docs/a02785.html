Detailed Description

template<typename T, typename U>
struct lumex::core::utility::traits::numeric::is_safe_comparable< T, U >

Both types (without cv / reference) are arithmetic with a specialized std::numeric_limits, so SafeComparator can compare them.

Derived from std::integral_constant like the standard traits: the standard library defines value in every standard, while a plain in-class static const member fails to link once it is odr-used (EXPECT_TRUE binds it to a reference) in a build without optimization.
