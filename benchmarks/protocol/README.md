# Protocol table compile time

What a protocol table of `lumex/core/protocol` costs the compiler: the table
DSL is C++11 macros and templates, so a large table is paid for in every
translation unit that includes it (the risk "C++11 template DSL compile time"
of the transport and protocol design).

## Method

`compile_time.py` compiles `compile_time.cpp` syntax-only (`/Zs` for cl.exe
and clang-cl, `-fsyntax-only -O0` for GCC and Clang) with
`BENCH_PROTOCOL_TABLE`:

- 0: the module headers only (the baseline);
- 1: a layout of 40 fields `u16_le_<scale<std::ratio<1, 100> > >`;
- 2: the layout and a protocol of 100 rows (the tables of the module tests,
  generated by the same rule into `bench_protocol_table.hpp`: one, two or no
  fields per row, a timeout and retries every tenth row, a flag every tenth
  row, the layout as the reply of every 25th row);
- 3: as 2, plus the run-time entries of all 100 rows and three client methods.

Each variant is compiled `--repeats` times at C++11 (C++14 for the cl
drivers, their lowest) and C++20; the median and the minimum are kept in
`results/compile_time.csv`. The cost of a table is its row minus row 0.

```text
python compile_time.py --compiler "cl=cl" --compiler "clang-cl=clang-cl" --repeats 5
```

## Results

Windows 10, MSVC 19.51 (Visual Studio 18) and clang-cl 21.1.7, median of 5,
milliseconds (23.10.2026):

| Toolchain | Standard | Headers | + 40-field layout | + 100 rows | + entries, methods |
| --- | --- | --- | --- | --- | --- |
| cl.exe | C++14 | 282 | 277 | 335 | 423 |
| cl.exe | C++20 | 541 | 540 | 591 | 689 |
| clang-cl | C++14 | 319 | 313 | 350 | 361 |
| clang-cl | C++20 | 491 | 511 | 532 | 545 |

A 100-row table costs about 50 ms (cl.exe) and 35 ms (clang-cl) over the
headers; building all 100 run-time entries adds 90 ms on cl.exe and 10 ms on
clang-cl. The 40-field layout is within the noise.
